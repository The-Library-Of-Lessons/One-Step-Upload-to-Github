One-Step GitHub Uploader NO PYTHON NEEDED
1. Command Builder 2. How It Works 3. Examples 4. Troubleshooting

Upload Any File to GitHub in One Step (cmd.exe + gh_upload.ps1)

Upload (commit and push) any file from your Windows PC straight into a specific GitHub folder using one Command Prompt line and gh_upload.ps1. PowerShell is already built into Windows 10/11, so the only external program you need is Git for Windows.

1. Interactive One-Step Command Builder

Paste your 3 paths below (extra quotes from "Copy as path" are cleaned automatically), then click Copy Command and paste into cmd.

Change this only if you move gh_upload.ps1 (for example to C:\Tools\gh_upload.ps1).
Tip: In File Explorer, hold Shift + Right-click your file → Copy as path, then paste here.
Open the target folder on GitHub in your browser and paste the address bar URL here.

      

    

  


  
  

    
2. Before You Start & What Happens Behind the Scenes

    
No need to memorize Git commands — here is the checklist and what gh_upload.ps1 does automatically.


    

      

        
One-Time Prerequisites

        
    
          
  • Git for Windows installed (git --version works in cmd).
    • 
          
  • gh_upload.ps1 saved on your PC.
    • 
          
  • GitHub write access (sign in if a browser popup asks).
    • 
          
  • File size under 100 MB (GitHub blocks standard uploads over 100 MB).
    • 
        

      

      

        
Interactive Mode (Optional)

        

          If you run just the script with no FILE= or URL=, it will ask you to paste them one by one:
        

        
powershell -NoProfile -ExecutionPolicy Bypass -File "d:\Adrian Files\01_Projects\WinProgram\JapFilenamefixer\gh_upload.ps1"

      

    


    

      

        
Step 1

        
Parse URL

        
Reads repo, branch, and converts %20 back into spaces.

      

      

        
Step 2

        
Sparse Clone

        
Downloads only the target folder into %TEMP%.

      

      

        
Step 3

        
Copy File

        
Creates the folder if missing and copies your file in.

      

      

        
Step 4

        
Commit & Push

        
Runs git add, git commit, and git push.

      

      

        
Step 5

        
Clean Up

        
Deletes the temporary folder from %TEMP%.

4. Quick Troubleshooting

    

      

        
          

            Message / Symptom
            What it means & how to fix it
          

        
        
          

            nothing to commit, working tree clean
            The exact same file (with identical contents) is already in that GitHub folder.
          

          

            Permission denied or 403
            You are not signed in to an account with write access to that repository. Sign in when the GitHub prompt appears.
          

          

            'git' is not recognized
            Install Git for Windows and reopen Command Prompt.
          

          

            Local file not found
            Check the path in FILE= for typos or extra quotes.
          

          

            The term '...' is not recognized
            Check the path in PS1= — make sure gh_upload.ps1 is actually saved at that location.
          

          

            Author identity unknown
            Run these two one-time commands first:
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
